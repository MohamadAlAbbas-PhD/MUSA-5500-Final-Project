Step 1 · From children to clusters

A DHS cluster is a village or urban neighbourhood where about 25–30 households were interviewed. For each cluster I calculate:

  • Anemia (%): the share of tested children aged 6–59 months with hemoglobin below 11 g/dL (adjusted for altitude by DHS)
  • Open defecation (%): the share of households with no toilet facility
  • Wealth: the average household wealth quintile (1 = poorest fifth of the country, 5 = richest)
  • Mothers with secondary school (%), urban/rural, and the interview month

"""Step 1. Turn DHS child records into one row per survey cluster.

Input : IPUMS-DHS extract (private)
Output: data/private/clusters.parquet  (private: contains GPS)
"""
import numpy as np
import pandas as pd
import pyreadstat
from config import DHS_FILE, PRIVATE, SSA, MIN_CHILDREN

cols = ["sample", "country", "year", "idhspsu", "intyear", "monthint", "urban",
        "wealthq", "educlvl", "kidalive", "kidagemo", "anemialvlkid",
        "opentoiletpsu", "gpslat", "gpslong", "perweight"]

print("Reading DHS extract (this takes a few minutes)...")
d, meta = pyreadstat.read_dta(str(DHS_FILE), usecols=cols)
print(f"  {len(d):,} child records, {d.country.nunique()} countries")

flow = [("All child records", len(d))]
def keep(mask, label):
    global d
    d = d[mask]
    flow.append((label, len(d)))

keep(d.country.isin(SSA.keys()), "Sub-Saharan Africa")
keep(d.kidalive == 1, "Child alive")
keep(d.kidagemo.between(6, 59), "Aged 6-59 months")
keep(d.anemialvlkid.isin([1, 2, 3, 4]), "Tested for anemia")
ok_gps = d.gpslat.notna() & d.gpslong.notna() & ~((d.gpslat == 0) & (d.gpslong == 0))
keep(ok_gps, "Cluster has GPS coordinates")
keep(d.opentoiletpsu.between(0, 100), "Cluster open defecation share available")
keep(d.urban.isin([1, 2]), "Urban/rural known")

d["anemic"] = (d.anemialvlkid <= 3).astype(float)            # any anemia (Hb < 11 g/dL, altitude-adjusted)
d["mod_sev"] = (d.anemialvlkid <= 2).astype(float)          # moderate or severe
d["mom_secondary"] = np.where(d.educlvl.isin([0, 1, 2, 3]), (d.educlvl >= 2).astype(float), np.nan)
d["country_name"] = d.country.map(SSA)
d["wealthq_ok"] = d.wealthq.where(d.wealthq.between(1, 5))

g = d.groupby("idhspsu")
cl = pd.DataFrame({
    "sample": g["sample"].first(),
    "country": g["country_name"].first(),
    "survey_year": g["year"].first(),
    "int_year": g["intyear"].agg(lambda s: s.mode().iat[0]).astype(int),
    "int_month": g["monthint"].agg(lambda s: s.mode().iat[0]).astype(int),
    "urban": (g["urban"].first() == 1).astype(int),
    "lat": g["gpslat"].first(),
    "lon": g["gpslong"].first(),
    "n_children": g.size(),
    "anemia_pct": g["anemic"].mean() * 100,
    "modsev_anemia_pct": g["mod_sev"].mean() * 100,
    "od_pct": g["opentoiletpsu"].first(),
    "wealth": g["wealthq_ok"].mean(),       # mean household wealth quintile, 1 = poorest, 5 = richest (relative to own country)
    "mom_secondary_pct": g["mom_secondary"].mean() * 100,
}).reset_index()

n_before = len(cl)
cl = cl[cl.n_children >= MIN_CHILDREN].copy()
flow.append((f"Children in clusters with >= {MIN_CHILDREN} tested children", int(cl.n_children.sum())))

cl.to_parquet(PRIVATE / "clusters.parquet", index=False)
pd.DataFrame(flow, columns=["step", "remaining"]).to_csv(PRIVATE / "sample_flow.csv", index=False)

print(pd.DataFrame(flow, columns=["step", "remaining"]).to_string(index=False))
print(f"Clusters: {n_before:,} -> {len(cl):,} kept; {cl.country.nunique()} countries; "
      f"{cl['sample'].nunique()} surveys; years {cl.int_year.min()}-{cl.int_year.max()}")
print(cl.groupby("country").size().sort_values(ascending=False).to_string())
print(cl[["anemia_pct", "od_pct", "wealth", "mom_secondary_pct", "n_children"]].describe().round(2).to_string())

Step 2 · Raster analysis: malaria and rainfall around each cluster

DHS moves every cluster’s GPS point by up to 2 km (urban) or 5 km (rural) to protect privacy. So instead of reading the raster at the point, I draw a buffer of that size around each point (in an equal-area projection, so the distances are in true metres) and take the mean raster value inside the buffer with rasterstats.zonal_stats.

  • Malaria: the Malaria Atlas Project raster for the year of the interview, read with rasterio.
  • Rainfall anomaly: with xarray, I sum CHIRPS rainfall over the 3 months before the interview month. I compare that total to the same 3 calendar months in every year from 1981 to 2010 at the same pixel: z = (this year − 30-year average) / 30-year standard deviation. Negative means drier than normal, positive means wetter.
  • Typical annual rainfall: the 1981–2010 average.

As a check, the rainfall anomalies correlate at 0.78 with the ones computed independently in R from the daily CHIRPS v3 data in my other project. The two use different CHIRPS versions and different window definitions, so they should not match exactly.

NoteShow the code: analysis/02_raster_features.py (geopandas, rasterio, rasterstats, xarray) 
"""Step 2. Add raster-based features to each cluster (zonal statistics).

  * Buffers: 2 km (urban) / 5 km (rural), matching DHS GPS displacement.
  * Malaria: Malaria Atlas Project P. falciparum prevalence (age 2-10),
             mean over the buffer, for the cluster's interview year.
  * Rainfall: CHIRPS monthly. Total rain in the 3 months before the interview
              month, as a standardized anomaly (z-score) against the same
              3 calendar months in 1981-2010 at that location.
              Plus the long-term (1981-2010) mean annual rainfall.

Input : data/private/clusters.parquet
Output: data/private/clusters_features.parquet
"""
import numpy as np
import pandas as pd
import geopandas as gpd
import rasterio
import xarray as xr
from rasterio.transform import from_origin
from rasterstats import zonal_stats
from config import PRIVATE, CHIRPS_MONTHLY, MAP_DIR, AFRICA_BBOX, AFRICA_EQUAL_AREA

cl = pd.read_parquet(PRIVATE / "clusters.parquet")
pts = gpd.GeoDataFrame(cl, geometry=gpd.points_from_xy(cl.lon, cl.lat), crs="EPSG:4326")

# ---- buffers (in metres, using an equal-area projection) ------------------
pts_m = pts.to_crs(AFRICA_EQUAL_AREA)
radius = np.where(pts_m.urban == 1, 2000, 5000)
buf = pts_m.buffer(radius).to_crs("EPSG:4326")
print(f"{len(buf):,} buffers built")

def zonal_mean(geoms, array, transform, nodata):
    out = zonal_stats(list(geoms), array, affine=transform, stats=["mean"],
                      nodata=nodata, all_touched=True)
    return np.array([o["mean"] if o["mean"] is not None else np.nan for o in out])

# ---- malaria (MAP PfPR 2-10), matched to interview year --------------------
cl["pfpr"] = np.nan
for yr, idx in cl.groupby(cl.int_year.clip(2000, 2021)).groups.items():
    with rasterio.open(MAP_DIR / f"PfPR_2-10_Africa_{yr}.tif") as src:
        arr = src.read(1).astype("float32")
        nod = src.nodata
        if nod is not None:
            arr[arr == nod] = np.nan
        arr[arr < 0] = np.nan
        cl.loc[idx, "pfpr"] = zonal_mean(buf.loc[idx], arr, src.transform, np.nan) * 100
    print(f"  malaria {yr}: {len(idx):,} clusters")

# ---- rainfall (CHIRPS monthly) --------------------------------------------
lon0, lat0, lon1, lat1 = AFRICA_BBOX
YEARS = range(1981, 2022)
BASE = (1981, 2010)

def open_year(y):
    ds = xr.open_dataset(CHIRPS_MONTHLY / f"CHIRPS_monthly_{y}.nc")
    return ds["precip"].sel(longitude=slice(lon0, lon1), latitude=slice(lat1, lat0))

# load all years once (Africa subset), as a dict of (12, ny, nx) float32 arrays
print("Loading CHIRPS (Africa subset)...")
rain = {}
for y in range(YEARS.start - 1, YEARS.stop):
    try:
        da = open_year(y)
    except FileNotFoundError:
        continue
    rain[y] = da.values.astype("float32")
    lats, lons = da.latitude.values, da.longitude.values
res = abs(float(lons[1] - lons[0]))
transform = from_origin(lons.min() - res / 2, lats.max() + res / 2, res, res)

def three_month_total(y, end_month):
    """Rain total for the 3 months ending in end_month (1-12) of year y."""
    tot = 0
    for k in range(3):
        m, yy = end_month - k, y
        if m <= 0:
            m, yy = m + 12, y - 1
        if yy not in rain:
            return None
        tot = tot + rain[yy][m - 1]
    return tot

# long-term mean annual rainfall (1981-2010)
annual = np.nanmean([rain[y].sum(axis=0) for y in range(BASE[0], BASE[1] + 1)], axis=0)
cl["rain_annual_mm"] = zonal_mean(buf, annual, transform, np.nan)

# 3-month anomaly: window ends the month BEFORE the interview month
end = cl.int_month - 1
end_year = np.where(end == 0, cl.int_year - 1, cl.int_year)
end = np.where(end == 0, 12, end)
cl["rain_end_month"], cl["rain_end_year"] = end, end_year
cl["rain_3mo_mm"] = np.nan
cl["rain_3mo_z"] = np.nan

for e in range(1, 13):
    base = [three_month_total(y, e) for y in range(BASE[0], BASE[1] + 1)]
    base = np.stack([b for b in base if b is not None])     # 1981 Jan/Feb windows need 1980 (no data)
    mu, sd = base.mean(axis=0), base.std(axis=0)
    sd[sd < 1] = np.nan                        # near-zero variability (desert) -> undefined
    for y in sorted(set(end_year[end == e])):
        idx = cl.index[(end == e) & (end_year == y)]
        tot = three_month_total(y, e)
        z = np.clip((tot - mu) / sd, -5, 5)
        cl.loc[idx, "rain_3mo_mm"] = zonal_mean(buf.loc[idx], tot, transform, np.nan)
        cl.loc[idx, "rain_3mo_z"] = zonal_mean(buf.loc[idx], z, transform, np.nan)
    print(f"  rainfall window ending month {e:2d} done")

cl.to_parquet(PRIVATE / "clusters_features.parquet", index=False)
print(cl[["pfpr", "rain_annual_mm", "rain_3mo_mm", "rain_3mo_z"]].describe().round(2).to_string())
print("Missing:", cl[["pfpr", "rain_3mo_z"]].isna().sum().to_dict())
NoteShow the code: analysis/03_download_boundaries.py (geoBoundaries API) 
"""Step 3. Download admin-1 (region/province) boundaries from the geoBoundaries API.

Source: geoBoundaries (www.geoboundaries.org), open licence, CC BY 4.0.
Output: data/public/admin1.geojson  (public data, safe to commit)
"""
import json
import time
import urllib.request
import geopandas as gpd
import pandas as pd
from config import PUBLIC, PRIVATE, SSA, ISO3

name_to_code = {v: k for k, v in SSA.items()}
countries = pd.read_parquet(PRIVATE / "clusters.parquet", columns=["country"]).country.unique()

def get_json(url, tries=4):
    for i in range(tries):
        try:
            with urllib.request.urlopen(url, timeout=120) as r:
                return json.loads(r.read())
        except Exception as e:
            print(f"    retry {i + 1}: {e}")
            time.sleep(2 ** i)
    raise RuntimeError(url)

frames = []
for c in sorted(countries):
    iso = ISO3[name_to_code[c]]
    meta = get_json(f"https://www.geoboundaries.org/api/current/gbOpen/{iso}/ADM1/")
    g = gpd.read_file(meta["simplifiedGeometryGeoJSON"])
    g = g[["shapeName", "geometry"]].rename(columns={"shapeName": "region"})
    g["country"], g["iso3"] = c, iso
    frames.append(g)
    print(f"  {c:15s} {iso}: {len(g)} regions")

adm = pd.concat(frames, ignore_index=True).to_crs("EPSG:4326")
adm["region_id"] = adm.iso3 + "_" + adm.groupby("iso3").cumcount().astype(str).str.zfill(3)
adm["geometry"] = adm.geometry.make_valid().simplify(0.01, preserve_topology=True)
adm[["region_id", "region", "country", "iso3", "geometry"]].to_file(PUBLIC / "admin1.geojson", driver="GeoJSON")
print(f"Saved {len(adm)} regions")

Step 3 · Clustering: k-means profiles and DBSCAN hotspots

  • k-means (scikit-learn) on the three standardized measures. Choosing k: the elbow plot and the silhouette score both point to k = 5.
  • DBSCAN on the latitude/longitude of the “all three high” clusters, with haversine (great-circle) distance. Settings: radius 50 km, at least 15 clusters. A sensitivity check covers radii of 25–100 km.
NoteShow the code: analysis/04_profiles_hotspots.py (scikit-learn KMeans, DBSCAN) 
"""Step 4. Cluster profiles (k-means) and spatial hotspots (DBSCAN).

  * k-means on three standardized measures: anemia, open defecation, malaria.
    Number of profiles chosen with the elbow method (and silhouette as a check).
  * DBSCAN on the locations of clusters in the "all three high" profile,
    using great-circle (haversine) distance, to find spatial hotspots.

Input : data/private/clusters_features.parquet
Output: data/private/clusters_profiles.parquet          (private)
        data/public/kmeans_elbow.csv, kmeans_profiles.csv, dbscan_summary.csv (public)
"""
import numpy as np
import pandas as pd
from sklearn.cluster import KMeans, DBSCAN
from sklearn.metrics import silhouette_score
from sklearn.preprocessing import StandardScaler
from config import PRIVATE, PUBLIC

K = 5                     # elbow bends around 4-5; silhouette is highest at 5 -> 5 profiles
EPS_KM, MIN_SAMPLES = 50, 15
MEASURES = ["anemia_pct", "od_pct", "pfpr"]

cl = pd.read_parquet(PRIVATE / "clusters_features.parquet")
# MAP leaves malaria-free areas (e.g. Lesotho, Eswatini, highlands) blank -> treat as 0 % prevalence
cl["pfpr_missing"] = cl.pfpr.isna().astype(int)
cl["pfpr"] = cl.pfpr.fillna(0)
cl = cl.dropna(subset=MEASURES).reset_index(drop=True)
X = StandardScaler().fit_transform(cl[MEASURES])

# ---- elbow ------------------------------------------------------------------
rng = np.random.default_rng(0)
sample = rng.choice(len(X), size=min(8000, len(X)), replace=False)
rows = []
for k in range(1, 11):
    km = KMeans(n_clusters=k, n_init=10, random_state=0).fit(X)
    sil = silhouette_score(X[sample], km.labels_[sample]) if k > 1 else np.nan
    rows.append({"k": k, "inertia": km.inertia_, "silhouette": sil})
elbow = pd.DataFrame(rows)
elbow.to_csv(PUBLIC / "kmeans_elbow.csv", index=False)
print(elbow.round(3).to_string(index=False))

# ---- final k-means ------------------------------------------------------------
km = KMeans(n_clusters=K, n_init=25, random_state=0).fit(X)
cl["profile_raw"] = km.labels_
cent = cl.groupby("profile_raw")[MEASURES].mean()
z = (cent - cl[MEASURES].mean()) / cl[MEASURES].std()

def name(row):
    hi = [lbl for lbl, col in [("anemia", "anemia_pct"), ("open defecation", "od_pct"), ("malaria", "pfpr")]
          if row[col] > 0.25]
    if len(hi) == 3:
        return "All three high"
    if not hi:
        return "All three low"
    return "High " + " + ".join(hi)

names = z.apply(name, axis=1)
# make names unique if two profiles share a label
for n, idx in names.groupby(names).groups.items():
    if len(idx) > 1:
        for j, i in enumerate(sorted(idx, key=lambda i: -z.loc[i].sum())):
            names[i] = f"{n} ({'stronger' if j == 0 else 'weaker'})"
order = z.sum(axis=1).sort_values(ascending=False).index          # 1 = highest burden
pid = {raw: i + 1 for i, raw in enumerate(order)}
cl["profile"] = cl.profile_raw.map(pid)
cl["profile_name"] = cl.profile_raw.map(names)

prof = (cl.groupby(["profile", "profile_name"])
          .agg(n_clusters=("anemia_pct", "size"), n_children=("n_children", "sum"),
               anemia_pct=("anemia_pct", "mean"), od_pct=("od_pct", "mean"), pfpr=("pfpr", "mean"),
               rain_3mo_z=("rain_3mo_z", "mean"), wealth=("wealth", "mean"),
               mom_secondary_pct=("mom_secondary_pct", "mean"), urban_pct=("urban", "mean"))
          .reset_index())
prof["urban_pct"] *= 100
prof["share_pct"] = 100 * prof.n_clusters / prof.n_clusters.sum()
prof.round(2).to_csv(PUBLIC / "kmeans_profiles.csv", index=False)
print(prof.round(1).to_string(index=False))

# ---- DBSCAN hotspots within the highest-burden profile -----------------------
top = cl.profile == 1
coords = np.radians(cl.loc[top, ["lat", "lon"]].to_numpy())
db = DBSCAN(eps=EPS_KM / 6371.0, min_samples=MIN_SAMPLES, metric="haversine",
            algorithm="ball_tree").fit(coords)
cl["hotspot"] = -1
cl.loc[top, "hotspot"] = db.labels_
cl["in_hotspot"] = (cl.hotspot >= 0).astype(int)

hs = (cl[cl.hotspot >= 0].groupby("hotspot")
        .agg(n_clusters=("lat", "size"), countries=("country", lambda s: ", ".join(sorted(s.unique()))),
             anemia_pct=("anemia_pct", "mean"), od_pct=("od_pct", "mean"), pfpr=("pfpr", "mean"))
        .sort_values("n_clusters", ascending=False).reset_index(drop=True))
hs.index = hs.index + 1
hs.index.name = "hotspot"
hs.round(1).to_csv(PUBLIC / "dbscan_summary.csv")
print(f"\nDBSCAN: {top.sum():,} clusters in profile 1 -> {len(hs)} hotspots, "
      f"{cl.in_hotspot.sum():,} clusters in a hotspot, {(db.labels_ == -1).sum():,} scattered")
print(hs.head(15).round(1).to_string())

# ---- sensitivity: how do hotspots change with the search radius? -------------
sens = []
for eps in (25, 50, 75, 100):
    lab = DBSCAN(eps=eps / 6371.0, min_samples=MIN_SAMPLES, metric="haversine",
                 algorithm="ball_tree").fit(coords).labels_
    cl[f"hot_{eps}"] = 0
    cl.loc[top, f"hot_{eps}"] = (lab >= 0).astype(int)
    sens.append({"eps_km": eps, "n_hotspots": int(lab.max() + 1), "clusters_in_hotspots": int((lab >= 0).sum()),
                 "share_pct": round(100 * (lab >= 0).mean(), 1)})
pd.DataFrame(sens).to_csv(PUBLIC / "dbscan_sensitivity.csv", index=False)
print(pd.DataFrame(sens).to_string(index=False))

cl.drop(columns="profile_raw").to_parquet(PRIVATE / "clusters_profiles.parquet", index=False)

Step 4 · Machine learning: predicting anemia

  • Train/test split of 80/20, 5-fold cross-validation, and a grid search over random forest depth, leaf size, and features per split.
  • A linear regression pipeline (StandardScaler → LinearRegression) as the baseline.
  • Spatial lag: the average anemia of the 10 nearest training clusters, found with a BallTree and haversine distance. Test clusters only “see” training neighbours, so no answers leak in.
  • Permutation importance shows which features matter. Out-of-fold predictions give every cluster a prediction from a model that never saw it, which feeds the error map.
NoteShow the code: analysis/05_predict_anemia.py (scikit-learn) 
"""Step 5. Predict cluster anemia prevalence: linear regression vs random forest.

  * Features: open defecation, malaria, rainfall anomaly, long-term rainfall,
    wealth, maternal education, urban, and a spatial lag (average anemia of the
    10 nearest *training* clusters, so the test set never leaks into features).
  * 80/20 train/test split, 5-fold cross-validation, grid search for the forest.
  * Out-of-fold predictions for every cluster -> where does the model miss?

Input : data/private/clusters_profiles.parquet
Output: data/private/clusters_final.parquet               (private)
        data/public/model_scores.csv, feature_importance.csv (public)
"""
import numpy as np
import pandas as pd
from sklearn.ensemble import RandomForestRegressor
from sklearn.inspection import permutation_importance
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, r2_score
from sklearn.model_selection import GridSearchCV, KFold, train_test_split
from sklearn.neighbors import BallTree
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from config import PRIVATE, PUBLIC

BASE_FEATURES = ["od_pct", "pfpr", "rain_3mo_z", "rain_annual_mm", "wealth",
                 "mom_secondary_pct", "urban"]
LABELS = {"od_pct": "Open defecation (%)", "pfpr": "Malaria prevalence (%)",
          "rain_3mo_z": "Rainfall anomaly, last 3 months", "rain_annual_mm": "Typical annual rainfall",
          "wealth": "Household wealth", "mom_secondary_pct": "Mothers with secondary school (%)",
          "urban": "Urban", "spatial_lag": "Anemia in nearby clusters"}
K_NEIGHBORS = 10
y_col = "anemia_pct"

cl = pd.read_parquet(PRIVATE / "clusters_profiles.parquet")
cl = cl.dropna(subset=BASE_FEATURES + [y_col]).reset_index(drop=True)
print(f"{len(cl):,} clusters with complete features")

def spatial_lag(train_idx, target_idx, k=K_NEIGHBORS):
    """Mean anemia of the k nearest training clusters (excluding the cluster itself)."""
    tr = cl.loc[train_idx]
    tree = BallTree(np.radians(tr[["lat", "lon"]].to_numpy()), metric="haversine")
    dist, ind = tree.query(np.radians(cl.loc[target_idx, ["lat", "lon"]].to_numpy()), k=k + 1)
    tr_ids = tr.index.to_numpy()[ind]                       # (n, k+1) training-cluster ids
    vals = tr[y_col].to_numpy()[ind]
    self_hit = tr_ids == np.asarray(target_idx)[:, None]
    vals = np.where(self_hit, np.nan, vals)
    # keep the first k non-self neighbours
    return np.array([row[~np.isnan(row)][:k].mean() for row in vals])

FEATURES = BASE_FEATURES + ["spatial_lag"]

def make_xy(train_idx, test_idx):
    Xtr = cl.loc[train_idx, BASE_FEATURES].copy(); Xtr["spatial_lag"] = spatial_lag(train_idx, train_idx)
    Xte = cl.loc[test_idx, BASE_FEATURES].copy();  Xte["spatial_lag"] = spatial_lag(train_idx, test_idx)
    return Xtr, cl.loc[train_idx, y_col], Xte, cl.loc[test_idx, y_col]

train_idx, test_idx = train_test_split(cl.index, test_size=0.2, random_state=42)
Xtr, ytr, Xte, yte = make_xy(train_idx, test_idx)

cv = KFold(5, shuffle=True, random_state=0)
grid = GridSearchCV(
    RandomForestRegressor(random_state=0, n_jobs=-1),
    {"n_estimators": [300], "max_depth": [10, 20, None], "min_samples_leaf": [5, 20],
     "max_features": [0.33, 0.66]},
    cv=cv, scoring="r2", n_jobs=1)

def cv_r2(make_model, feats):
    """Average R2 across the 5 cross-validation folds of the training set."""
    return np.mean([r2_score(ytr.iloc[v], make_model().fit(Xtr[feats].iloc[t], ytr.iloc[t])
                             .predict(Xtr[feats].iloc[v])) for t, v in cv.split(Xtr)])

grid.fit(Xtr[FEATURES], ytr)                      # grid search with 5-fold CV
best = {k: v for k, v in grid.best_params_.items()}
make_linear = lambda: make_pipeline(StandardScaler(), LinearRegression())
make_rf = lambda: RandomForestRegressor(random_state=0, n_jobs=-1, **best)

rows = []
for name, make_model, feats in [("Linear regression", make_linear, FEATURES),
                                ("Random forest", make_rf, FEATURES),
                                ("Random forest (no spatial lag)", make_rf, BASE_FEATURES)]:
    model = make_model().fit(Xtr[feats], ytr)
    pred = model.predict(Xte[feats])
    rows.append({"model": name, "cv_r2": cv_r2(make_model, feats), "test_r2": r2_score(yte, pred),
                 "test_mae": mean_absolute_error(yte, pred)})
    print(rows[-1])
    if name == "Linear regression":
        linear = model
print("Best forest:", grid.best_params_)
scores = pd.DataFrame(rows)
scores.round(3).to_csv(PUBLIC / "model_scores.csv", index=False)

# ---- which factors matter? (permutation importance on the test set) ---------
rf = grid.best_estimator_
imp = permutation_importance(rf, Xte[FEATURES], yte, n_repeats=10, random_state=0, n_jobs=-1)
lin_coef = linear.named_steps["linearregression"].coef_
fi = pd.DataFrame({"feature": FEATURES, "label": [LABELS[f] for f in FEATURES],
                   "rf_importance": imp.importances_mean, "rf_importance_sd": imp.importances_std,
                   "linear_std_coef": lin_coef})
fi.sort_values("rf_importance", ascending=False).round(4).to_csv(PUBLIC / "feature_importance.csv", index=False)
print(fi.sort_values("rf_importance", ascending=False).round(3).to_string(index=False))

# ---- out-of-fold predictions for every cluster (for the error map) ----------
cl["pred_rf"] = np.nan
cl["pred_linear"] = np.nan
for t, v in KFold(5, shuffle=True, random_state=1).split(cl):
    Xa, ya, Xb, _ = make_xy(cl.index[t], cl.index[v])
    cl.loc[cl.index[v], "pred_rf"] = make_rf().fit(Xa, ya).predict(Xb)
    cl.loc[cl.index[v], "pred_linear"] = make_linear().fit(Xa, ya).predict(Xb)
cl["resid_rf"] = cl[y_col] - cl.pred_rf             # + = model under-predicts anemia
cl["abs_err_rf"] = cl.resid_rf.abs()
print("Out-of-fold R2 (rf / linear):", round(r2_score(cl[y_col], cl.pred_rf), 3),
      round(r2_score(cl[y_col], cl.pred_linear), 3))

cl.to_parquet(PRIVATE / "clusters_final.parquet", index=False)

Step 5 · Privacy-safe aggregation and the website

DHS rules do not allow publishing cluster GPS points or microdata. The raw DHS data and every cluster-level file stay on my computer. They are excluded by .gitignore and never pushed to GitHub. Everything on this site is aggregated:

  • Hexagons (H3 resolution 4, ~23 km edge, ~1,770 km²), shown only if they hold at least 3 clusters. The real H3 cell ids are dropped.
  • Admin-1 regions, shown only with at least 5 clusters.
  • Malaria and rainfall rasters are open data and are shown in full.
NoteShow the code: analysis/06_public_outputs.py (h3, geopandas) 
"""Step 6. Aggregate private cluster results into PUBLIC, non-identifying outputs.

DHS forbids sharing cluster GPS points, so everything published is aggregated:
  * hexagons (H3 resolution 4, ~23 km edge, ~1,770 km2), hidden if < 3 clusters
  * admin-1 regions, hidden if < 5 clusters
  * open raster layers (MAP malaria, CHIRPS rainfall) as map images

Output (data/public/): hexes.geojson, regions.geojson, profiles_by_country.csv,
                       raster_*.png + raster_bounds.json, sample_summary.json
"""
import json
import h3
import numpy as np
import pandas as pd
import geopandas as gpd
import rasterio
import xarray as xr
import matplotlib
import matplotlib.image
from matplotlib import cm, colors
from shapely.geometry import Polygon
from config import PRIVATE, PUBLIC, MAP_DIR, CHIRPS_MONTHLY, AFRICA_BBOX

H3_RES, MIN_HEX, MIN_REGION = 4, 3, 5
cl = pd.read_parquet(PRIVATE / "clusters_final.parquet")
allc = pd.read_parquet(PRIVATE / "clusters_profiles.parquet")      # includes clusters w/o all model features
allc = allc.merge(cl[["idhspsu", "pred_rf", "resid_rf", "abs_err_rf"]], on="idhspsu", how="left")
n_prof = allc.profile.max()

def summarise(g):
    out = g.agg(n_clusters=("idhspsu", "size"), n_children=("n_children", "sum"),
                anemia_pct=("anemia_pct", "mean"), modsev_anemia_pct=("modsev_anemia_pct", "mean"),
                od_pct=("od_pct", "mean"), pfpr=("pfpr", "mean"),
                rain_3mo_z=("rain_3mo_z", "mean"), rain_annual_mm=("rain_annual_mm", "mean"),
                wealth=("wealth", "mean"), mom_secondary_pct=("mom_secondary_pct", "mean"),
                urban_pct=("urban", "mean"), in_hotspot_pct=("in_hotspot", "mean"),
                pred_anemia_pct=("pred_rf", "mean"), resid=("resid_rf", "mean"), abs_err=("abs_err_rf", "mean"),
                year_min=("int_year", "min"), year_max=("int_year", "max"),
                hot_25=("hot_25", "mean"), hot_50=("hot_50", "mean"), hot_75=("hot_75", "mean"),
                hot_100=("hot_100", "mean"),
                country=("country", lambda s: s.mode().iat[0]))
    for e in (25, 50, 75, 100):
        out[f"hot_{e}"] *= 100
    out["urban_pct"] *= 100
    out["in_hotspot_pct"] *= 100
    shares = pd.crosstab(g.obj[g.keys] if isinstance(g.keys, str) else g.obj[g.keys[0]],
                         g.obj["profile"], normalize="index") * 100
    shares = shares.reindex(columns=range(1, n_prof + 1), fill_value=0)
    shares.columns = [f"profile{p}_pct" for p in shares.columns]
    out = out.join(shares)
    out["profile"] = shares.to_numpy().argmax(axis=1) + 1          # most common profile
    names = allc.drop_duplicates("profile").set_index("profile").profile_name
    out["profile_name"] = out.profile.map(names)
    # dominant DBSCAN hotspot id (0 = none)
    hs = g.obj[g.obj.hotspot >= 0].groupby(g.keys).hotspot.agg(lambda s: s.mode().iat[0] + 1)
    out["hotspot_id"] = hs.reindex(out.index).fillna(0).astype(int)
    return out

# ---- hexagons ------------------------------------------------------------------
allc["hex"] = [h3.latlng_to_cell(la, lo, H3_RES) for la, lo in zip(allc.lat, allc.lon)]
hx = summarise(allc.groupby("hex"))
hx = hx[hx.n_clusters >= MIN_HEX].reset_index()
hx["geometry"] = [Polygon([(lo, la) for la, lo in h3.cell_to_boundary(h)]) for h in hx.hex]
hx = gpd.GeoDataFrame(hx, crs="EPSG:4326").round(2)
hx["hex"] = range(1, len(hx) + 1)                                   # drop the real H3 id
hx.to_file(PUBLIC / "hexes.geojson", driver="GeoJSON")
print(f"Hexes: {len(hx):,} shown (>= {MIN_HEX} clusters), covering {hx.n_clusters.sum():,} of {len(allc):,} clusters")

# ---- admin-1 regions -----------------------------------------------------------
adm = gpd.read_file(PUBLIC / "admin1.geojson")
pts = gpd.GeoDataFrame(allc, geometry=gpd.points_from_xy(allc.lon, allc.lat), crs="EPSG:4326")
pts = gpd.sjoin(pts, adm[["region_id", "geometry"]], how="left", predicate="within")
# clusters falling just outside a polygon (coast, displacement) -> nearest region
miss = pts.region_id.isna()
if miss.any():
    near = gpd.sjoin_nearest(pts.loc[miss, ["geometry"]].to_crs(3857),
                             adm[["region_id", "geometry"]].to_crs(3857), how="left")
    pts.loc[miss, "region_id"] = near.groupby(level=0).region_id.first()
pts = pd.DataFrame(pts.drop(columns=["geometry", "index_right"]))
rg = summarise(pts.groupby("region_id")).drop(columns="country")
rg = rg[rg.n_clusters >= MIN_REGION]
regions = adm.merge(rg.reset_index(), on="region_id", how="left").round(2)
regions.to_file(PUBLIC / "regions.geojson", driver="GeoJSON")
print(f"Regions: {rg.shape[0]} of {len(adm)} with >= {MIN_REGION} clusters")

# ---- by country ------------------------------------------------------------------
bc = (pd.crosstab(allc.country, allc.profile_name, normalize="index") * 100).round(1)
bc["n_clusters"] = allc.groupby("country").size()
bc["anemia_pct"] = allc.groupby("country").anemia_pct.mean().round(1)
bc.reset_index().to_csv(PUBLIC / "profiles_by_country.csv", index=False)

# ---- open raster layers as images (for map overlays) -----------------------------
def to_png(arr, path, cmap, vmin, vmax):
    rgba = matplotlib.colormaps[cmap](colors.Normalize(vmin, vmax)(arr))
    rgba[..., 3] = np.where(np.isnan(arr), 0, 0.75)
    matplotlib.image.imsave(path, rgba)

bounds = {}
for yr in (2005, 2020):
    with rasterio.open(MAP_DIR / f"PfPR_2-10_Africa_{yr}.tif") as src:
        a = src.read(1).astype("float32")
        a[a < 0] = np.nan
        a = a[::2, ::2] * 100                                       # ~10 km, enough for a web map
        to_png(a, PUBLIC / f"raster_malaria_{yr}.png", "YlOrRd", 0, 70)
        b = src.bounds
        bounds[f"malaria_{yr}"] = [[b.bottom, b.left], [b.top, b.right]]

lon0, lat0, lon1, lat1 = AFRICA_BBOX
ann = []
for y in range(1981, 2011):
    da = xr.open_dataset(CHIRPS_MONTHLY / f"CHIRPS_monthly_{y}.nc")["precip"]
    ann.append(da.sel(longitude=slice(lon0, lon1), latitude=slice(lat1, lat0))[:, ::4, ::4].sum("time").values)
ann = np.mean(ann, axis=0)
ann[ann <= 0] = np.nan
to_png(ann, PUBLIC / "raster_rain_annual.png", "YlGnBu", 0, 2500)
bounds["rain_annual"] = [[lat0, lon0], [lat1, lon1]]
json.dump(bounds, open(PUBLIC / "raster_bounds.json", "w"))

# ---- headline numbers ------------------------------------------------------------
flow = pd.read_csv(PRIVATE / "sample_flow.csv")
summary = {"children": int(allc.n_children.sum()), "clusters": len(allc),
           "countries": int(allc.country.nunique()), "surveys": int(allc["sample"].nunique()),
           "year_min": int(allc.int_year.min()), "year_max": int(allc.int_year.max()),
           "anemia_pct": round(float(allc.anemia_pct.mean()), 1),
           "hex_shown": len(hx), "regions_shown": int(rg.shape[0]),
           "sample_flow": flow.to_dict(orient="records")}
json.dump(summary, open(PUBLIC / "sample_summary.json", "w"), indent=2)
print(json.dumps({k: v for k, v in summary.items() if k != "sample_flow"}))

Limitations

  • Cross-sectional data: this is about association and prediction, not cause and effect.
  • Surveys from different years are pooled (2000–2021). A hexagon can mix surveys taken 15 years apart.
  • Malaria is modelled, not measured in the cluster. MAP surfaces are themselves smoothed predictions.
  • Small samples: many clusters have 5–15 tested children, so cluster anemia rates are noisy. This limits how well any model can do.
  • GPS displacement blurs the raster extraction, which the buffers only partly fix.
  • Country coverage: only surveys that tested children’s hemoglobin and released GPS are included. In this extract, DR Congo and Côte d’Ivoire have no GPS, Zambia and Chad have no anemia classification, and Kenya has too few tested children with complete data. All five drop out.
